CRITICAL INFORMATION
═════════════════════════════════════════════════════════════════════════════

⚠️  NO FABRICATED DATA
    Every value is from real F1 historical records:
    • F1DB (primary source, GitHub releases)
    • Jolpica-F1 (fallback/verification)
    • OpenF1 (telemetry 2023+)
    Cross-verified with Wikipedia and FIA records

⚠️  DATA LEAKAGE PREVENTION
    Use PRE-QUALIFYING version if predicting BEFORE qualifying
    Use POST-QUALIFYING version if predicting AFTER qualifying
    Read DATA_LEAKAGE_POLICY.md carefully!

⚠️  HISTORICAL LIMITATIONS
    • Lap times: Only 1996-2026 (earlier = NULL)
    • Pit stops: Duration only from 2003 onward
    • Qualifying: Formats changed multiple times pre-2003
    • Telemetry: Only 2023+ via OpenF1
    See DATA_PROVENANCE.md for complete matrix

⚠️  NOT EQUIVALENT ACROSS ERAS
    • Different scoring systems
    • Different grid sizes (8 cars in 1950 → 20 in 2026)
    • Different measurement precision
    • Different race distances
    Use era-aware analysis where appropriate
