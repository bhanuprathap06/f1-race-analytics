================================================================================
F1 RACE PREDICTOR - LOCAL TERMINAL EXECUTION GUIDE
Machine Learning Pipeline (No Colab, Terminal Only)
================================================================================

PREREQUISITES:
  • macOS/Linux/Windows with Terminal
  • Python 3.8 or higher
  • ~500MB free disk space

================================================================================
STEP 1: NAVIGATE TO PROJECT DIRECTORY
================================================================================

Open Terminal and navigate to your project folder:

$ cd ~/Desktop/formulaOne

Verify you're in the right directory:

$ pwd
# Should show: /Users/YOUR_USERNAME/Desktop/formulaOne

$ ls -la
# Should show F1_RACE_PREDICTOR_ML_ENGINE.py, SETUP_LOCAL.sh, etc.

================================================================================
STEP 2: RUN SETUP SCRIPT (One-time only)
================================================================================

Make setup script executable:

$ chmod +x SETUP_LOCAL.sh

Run the setup script:

$ ./SETUP_LOCAL.sh

This will:
  ✓ Check Python version
  ✓ Create virtual environment (venv/)
  ✓ Install all required packages (pandas, numpy, scikit-learn, xgboost)
  ✓ Create output directories (F1_ML_DATASETS/trained_models/)

Expected output:
  Python 3.x.x
  ✓ Virtual environment activated
  ✓ All packages installed successfully
  ✓ Directories created

================================================================================
STEP 3: ACTIVATE VIRTUAL ENVIRONMENT
================================================================================

$ source venv/bin/activate

You should see (venv) prefix in your terminal:

(venv) $ _

This isolates your Python environment for this project.

================================================================================
STEP 6: LOAD & USE TRAINED MODELS
================================================================================

Create a Python script to load and use models:

$ cat > predict_race.py << 'EOF'
import pickle
import pandas as pd
import numpy as np

# Load the best model (Stacking Ensemble for winner prediction)
with open('F1_ML_DATASETS/trained_models/winner_stacking_ensemble.pkl', 'rb') as f:
    model = pickle.load(f)

# Load feature columns
with open('F1_ML_DATASETS/trained_models/feature_columns.pkl', 'rb') as f:
    features = pickle.load(f)

print("✓ Model loaded successfully")
print(f"✓ Model type: {type(model)}")
print(f"✓ Features required: {len(features)}")
print(f"✓ Features: {features[:5]}... (showing first 5)")

# Example: Make a prediction
# (In practice, you'd load real race data here)
example_data = pd.DataFrame({feat: [0.5] for feat in features})
prediction = model.predict(example_data)
probability = model.predict_proba(example_data)

print(f"\n✓ Example prediction: {prediction[0]}")
print(f"✓ Confidence: {probability[0][1]:.2%}")
EOF

================================================================================
TROUBLESHOOTING
================================================================================

ERROR: "No module named 'pandas'"
  SOLUTION: source venv/bin/activate && pip install pandas

ERROR: "Python 3.8 or higher required"
  SOLUTION: python3 --version (use python3 if python doesn't work)

ERROR: "Permission denied" when running SETUP_LOCAL.sh
  SOLUTION: chmod +x SETUP_LOCAL.sh

ERROR: Long execution time (>20 minutes)
  SOLUTION: Normal for first run; subsequent runs faster
  ALTERNATIVE: Reduce n_estimators in ML_ENGINE code (line ~300)

ERROR: Out of memory
  SOLUTION:
    - Reduce dataset size in STEP 1 (change num_records)
    - Or, run on machine with 8GB+ RAM

ERROR: Models not saving
  SOLUTION: Check write permissions: ls -la F1_ML_DATASETS/
